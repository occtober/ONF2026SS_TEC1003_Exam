# Frontend – Highsoft Course Portal

This folder contains the frontend for the Highsoft Course Portal, developed as part of the First Year Industry Project.

## Structure

- `index.html` – landing page
- `course-detail.html` – course overview page
- `module1.html` – lesson/content page
- `module2.html` – lesson/content page
- `course_summary.html` – summary/completion page

- `css/` – styling, variables, components and layout
- `js/` – frontend JavaScript and interactions
- `images/` – logos, illustrations and other assets
- `design-system/` – design system documentation, tokens and component notes


## Implementation Notes

- Styling is based on variables and component structure from the design system in Figma
- HTML structure is aligned with the design system
- Mobile responsiveness is adjusted based on the original desktop design
- Images and assets have been added to the frontend structure
